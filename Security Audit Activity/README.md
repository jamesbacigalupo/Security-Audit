\# Google Cybersecurity Certificate: Security Audit Portfolio Project



\## 📌 Project Overview

This project is a practical security audit completed as part of the \*\*Google Cybersecurity Professional Certificate\*\* program on Coursera. The objective was to review the security posture of a fictional organization, identify vulnerabilities, controls and gaps in compliance to provide actionable recommendations.



\## 🏢 Scenario Context

\*Note: To respect Coursera's Honor Code, the raw, proprietary course materials and background files provided by Google have been omitted. The context utilized for the audit is summarized below:\*

\* \*\*Organization Type:\*\* \[Small U.S. manufacturer. The business has a single physical location, which serves as their main office, a storefront, and warehouse for their products. They have online presence abroad.]

\* \*\*Scope of Audit:\*\* \[The scope of this audit is defined as the entire security program at the company, this includes their assets like employee equipment and devices, their internal network, and their systems.]

\* \*\*Framework Used:\*\* NIST Cybersecurity Framework (CSF) / NIST SP 800-53

* **Fictional Company Name:** [Botium Toys] (Utilized strictly as a simulated case study for this audit)


\## 📂 Repository Structure

\* \*\*`Security\_Audit\_Report.pdf`\*\* - The final deliverable containing the controls and compliance checklist and recommendations.
